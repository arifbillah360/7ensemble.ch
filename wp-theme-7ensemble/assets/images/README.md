# Images Folder

This folder contains all images and assets for the 7 Ensemble website.

## Usage
Place your image files here and reference them in HTML/CSS as:
- From HTML files in root: `images/your-image.png`
- From CSS: `../images/your-image.png`

## Recommended Image Types
- Logo files (PNG with transparency)
- Hero images
- Icons and graphics
- Background images
